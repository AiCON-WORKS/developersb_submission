# 仕入品管理アプリ

### 概要
社内の購買部門や設計部門担当者が、仕入品を登録、参照する際に使用します。



### URL



### 開発背景
どんな商品を仕入ているか実績を確認する事で、
商品選定の時間を短縮する事や一元管理が可能になり、効率化を図れると考えた為です



### 機能一覧


ログイン画面
* ログインIDとパスワードでの認証機能の実装

仕入品登録画面
* 入力フォームとDB連携の実装
